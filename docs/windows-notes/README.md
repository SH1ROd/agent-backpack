# Windows 经验笔记

这里记录 Windows 环境中反复出现或容易被更新重置的小问题：现象、证据、前因后果、处理方式、回退步骤和长期经验。

## 为什么单独建目录

Windows 功能更新和累积更新经常会：

- 重置界面开关或注册表 tweak；
- 用新的设置层覆盖旧的做法；
- 让“键还在”和“行为已变”同时成立；
- 不提供面向用户的设置变更历史。

把这些案例留档，可以在下次遇到同类问题时快速判断“这是更新导致的行为变化”还是“异常/恶意程序”，并直接复用验证和回退步骤。

## 文件命名

```text
YYYY-MM-DD-简短主题.md
```

例如：`2026-11-28-windows11-context-menu.md`。

## 每篇笔记建议包含

1. 现象与影响范围
2. 系统版本、更新记录、时间线
3. 可复现的证据（命令与输出摘要）
4. 根因或最可能的根因（明确区分“已证实”和“推断”）
5. 处理方案（优先官方设置，其次注册表/脚本）
6. 验证方式
7. 回退方式
8. 经验与后续检查点
